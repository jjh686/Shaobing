# 云台 C 板：通信稳定性修复-05整合-20261120

推荐烧录 `Gimbal_ChassisLink.elf`，也可选同名 HEX；BIN 起始地址为 `0x08000000`。三种格式是同一程序，选一种即可。

接线：USB 接小电脑；CAN1 接底盘 CAN2；UART3/DBUS 接 S.BUS。板间 CAN 为 1 Mbps，H 对 H、L 对 L，两板共地。

本包来自 05_云台 完整工程；保留现有云台电机/俯仰控制及上电自瞄配置。板间模块独立初始化 SBUS，用于底盘许可；CAN1 同时服务 yaw，保留电机自动重发及邮箱保护。

两块板必须分别连接 SWD，核对目标板后烧写、校验并复位。本次仅生成固件，未访问硬件、未烧录、未进行实物通信验收。

当前配套路径与复测步骤见 05_云台/docs/通信稳定性修复与工程归属-20261120.md。烧录后从 04_底盘电控（含通信）运行 tools/zero_test.sh 执行 10 秒 STOP/ACK 测试。
