# SWD 检测结果：USB 未枚举原因

日期：2026-11-11。电机主电源断开由用户确认。本次只做读取与短暂暂停/恢复，没有请求复位、擦写 Flash 或下发运动指令。

## 结论

SWD 已连通 STM32F407（芯片 ID 0x100f6413，Flash 1 MiB）。芯片 UID 与以前备份中的板子相同，但当前启动向量及程序片段与之前成功通信的 94432 字节单板导航固件不同，也与烧录前原始备份不同。

当前板上运行的程序片段在 0x08001060 附近，采样 PC=0x08001070，循环调用 GPIO 操作函数，使用 GPIOH 的 10/11/12 位掩码。它的具体源码来源尚不清楚，不能依据用户描述认定为之前那份 USB 通信测试程序。

现场读取 RCC_AHB2ENR=0，USB OTG FS 时钟未使能；GPIOA 的 PA11/PA12 未配置为 USB 复用功能，USB 寄存器读数为零。由此确认当前程序尚未提供正常运行的 USB CDC 接口，能够解释 USB 供电亮灯但电脑没有串口的现象。尚不能据此证明 USB 线/插座的数据触点完全正常，需正确 USB 固件运行后再验。

先前根据旧工程提出的 IMU 初始化阻塞只是一种静态代码猜测；本次实板发现固件版本不同，不能把该猜测当作本次已确认根因。
