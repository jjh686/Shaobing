## 4. 现在怎么运行

日常详细命令和预期状态以 `本机配置与启动.md` 为准：

```bash
# 不接硬件，检查整套程序启动
bash scripts/run_sentry.sh check

# 接雷达，不接 C 板，独立建图
bash scripts/run_mapping.sh rviz:=true

# 建图运行期间，在第二个终端保存
bash scripts/run_mapping.sh --save

# 建图期间只读检查，使用根命名空间
bash scripts/observe_navigation.sh --namespace '' --duration 15

# 完整导航/通信入口运行期间，只读检查机器人命名空间
bash scripts/observe_navigation.sh --duration 15
```

命令先在本工程根目录执行。建图和完整导航等含雷达入口不能同时运行，避免争用雷达端口。Ctrl+C 正常结束；有点云时建图会保存当前成果。独立建图保持当前雷达水平安装参数，不要求伪造云台角度。

录包软件已具备。需要留存后续真实雷达数据时，可在独立建图运行期间另开终端，进入本工程后执行：

```bash
source scripts/local_env.sh
ros2 bag record -o "$RM_NAV_RUNTIME/log/lidar_bag_$(date +%Y%m%d_%H%M%S)" \
  /livox/lidar /livox/imu /tf /tf_static /cloud_registered /aft_mapped_to_init
```

该命令仅适用于独立建图的根命名空间；完整入口的话题有 `/red_standard_robot1/` 前缀。本轮未运行这条真实录包命令。
