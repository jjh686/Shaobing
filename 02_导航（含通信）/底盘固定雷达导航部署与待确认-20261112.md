## 2. 本次电脑端改动

- 新增 `scripts/run_chassis_nav.sh` 和 `src/rm_chassis_comm/launch/chassis_navigation.launch.py`，作为本车当前入口。
- 新增 `local/chassis_nav2_params.yaml`：导航、定位和代价地图的车体参考帧统一为 `base_footprint`，不再依赖 `gimbal_yaw_fake`。
- 雷达唯一固定 TF 读取 `local/measured_mounting.yaml`：`base_footprint → front_mid360`，位置 `[0,0,0.20] m`、名义 RPY 为零、轮廓四边距中心各 0.30 m。参数沿用用户此前确认值，最终安装变动时须更新。
- 不启动 `sentry_frame_bridge` 或 `fake_vel_transform`，不要求云台关节反馈和 `frame_ready`。控制器已在车体系计算速度，无须再旋转一次。
- 控制器和行为恢复速度统一进入 `cmd_vel_controller → velocity_smoother → cmd_vel_nav2_result → chassis_comm → USB`。修复原行为节点未走统一速度平滑通路的问题。
- Humble 使用 `geometry_msgs/Twist` 直接接 Nav2 输出；本模式 `use_stamped_commands=false`。仍按接收时间做 150 ms 指令超时，反馈超时 250 ms，发送频率 50 Hz。
- 调低平移/旋转速度、加减速度与跟踪参数；USB 节点再次限制平移向量模长 ≤0.30 m/s，角速度 ≤0.50 rad/s。
- 修复组合启动布尔表达式对小写 `false` 的兼容；组合和独立进程模式均已启动检查。
- 修复 `sensor_scan_generation` 原里程计速度计算：按消息时间戳求差、速度转到当前 child 车体坐标；首次、重复/倒退时间戳、切换坐标系时清速度并重设基线，避免首帧尖峰和四元数符号翻转产生假转速。
- 新增本车 `local/chassis_nav.rviz`，去掉依赖旧云台 URDF 的 RobotModel，坐标轴改为底盘参考帧。
- 环境检查与运行观察支持 `--profile chassis`；诊断增加实际坐标帧和门控配置。
- gateway 的 `pc/run.sh` 增加 `chassis_navigation` 转发入口。原 `navigation` 和 `run_sentry.sh` 仍是完整云台方案，本车现阶段使用新入口。

原始配置保留，修改前备份位置见 `local/chassis_nav_backup_location.txt`。原完整云台方案 `local/sentry_real.yaml` 的 `geometry_confirmed=false` 保留。

## 3. 运行入口

命令完整版见 [底盘导航启动与联调指令 TXT](底盘导航启动与联调指令-20261112.txt)。先进入：

```bash
cd '/home/wangjiaming/桌面/rm_nav_source_20261110(zbh)'
```

| 命令 | 启动内容 |
| --- | --- |
| `bash scripts/run_chassis_nav.sh preview` | 仅通信预览和雷达固定 TF，无 USB/雷达/Nav2 |
| `bash scripts/run_chassis_nav.sh check` | 导航软件整套启动，不开 USB 和雷达，Nav2 不自动激活 |
| `bash scripts/run_chassis_nav.sh sensors use_rviz:=true` | 雷达、定位、导航软件；无 USB，Nav2 不自动激活 |
| `bash scripts/run_chassis_nav.sh usb PORT` | 仅 USB 通信与固定 TF；默认不使能 |
| `bash scripts/run_chassis_nav.sh navigation PORT use_rviz:=true` | USB、雷达、定位、Nav2 自动激活；底盘通信仍默认不使能 |

每次只运行一个占用物理 USB 的程序。先停止零速测试和串口助手，再启动 ROS。默认测试地图仅是实验室当前位置可见区域，**不能当作新场地地图**。正式定位/导航应通过 `map:=... prior_pcd_file:=...` 同时选择同一次建图的 `map.yaml`、`map.pcd`。

独立建图入口继续用 `bash scripts/run_mapping.sh`，另一个终端 `bash scripts/run_mapping.sh --save`。该流程不控制底盘；手动移动雷达/整车时保持安装刚性。
