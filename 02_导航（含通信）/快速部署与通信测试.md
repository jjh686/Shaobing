# 快速部署与通信测试

适用对象：已有运行环境的原生 Ubuntu 22.04 小电脑，ROS2 Humble，一根 USB 连接云台板、云台通过 CAN 连接底盘板。

## 1. 复制和解压

将“导航源码与通信测试（不含环境）-20261110.zip”复制到小电脑，用文件管理器解压，将解压得到的整个 `rm_nav_source_20261110` 文件夹放到当前用户主目录。

最终目录应为：

```text
~/rm_nav_source_20261110/
├── src/
│   ├── pb2025_sentry_nav/
│   └── rm_chassis_comm/
├── scripts/
├── 快速部署与通信测试.md
└── 先读我-部署与通信测试.md
```

这是源码部署包，需要在小电脑上编译。包内没有 SDK、ROS安装环境、Gazebo工程、采集地图及云台/底盘完整烧录工程。沿用小电脑已有环境，不覆盖已有自瞄和雷达驱动工作区。

## 2. 编译 PC 通信包

以下命令均在小电脑的 Ubuntu 终端执行：

```bash
cd ~/rm_nav_source_20261110
bash scripts/build_comm.sh
```

通信包编译不依赖雷达驱动，也不会安装依赖、修改系统网络或打开真实串口。编译失败时保留完整错误，先解决再继续。

## 3. 软件通信预览

第一个终端：

```bash
cd ~/rm_nav_source_20261110
bash scripts/comm_test.sh preview
```

第二个终端：

```bash
cd ~/rm_nav_source_20261110
bash scripts/watch_comm.sh
```

预期诊断包含：

```text
Preview: hardware not opened
route = 2
enabled = false
```

ROS诊断是键值列表，实际显示可能分行排列；核对字段和值即可。本阶段不打开真实USB，验证的是程序启动和ROS消息传输。第一个终端按 Ctrl+C 退出预览，再进入实物测试。

## 4. 实物失能通信测试

连接方式：

```text
小电脑 → 一根USB → 云台控制板 → CAN → 底盘控制板
```

云台负责USB协议分流、自瞄处理、关节反馈及底盘CAN转发；底盘负责接收速度、安全许可、超时保护与电机控制。

电控须已在云台和底盘两侧接入本次协议。仅接原自瞄固件不能判定导航协议已经可用。测试期间保持底盘失能和实体急停可用；关闭其他占用物理串口的程序。本步骤不启用自瞄SP代理，不测试车辆运动。

查看USB设备：

```bash
ls -l /dev/serial/by-id/
```

将下列占位路径替换成实际设备路径：

```bash
cd ~/rm_nav_source_20261110
bash scripts/comm_test.sh usb /dev/serial/by-id/实际设备名
```

第二个终端继续运行：

```bash
bash scripts/watch_comm.sh
```

全程保持 `enabled=false`，不要调用使能服务。检查：

- `USB connected; STOP handshake only`：串口打开，但还不能证明底盘回复。
- `received_bytes` 增长：USB收到了字节。
- `decoded_feedback` 增长：收到通过分帧和CRC解码的底盘反馈。
- `feedback_age_ms` 为数值并持续刷新：本次会话、已发送序号和ACK等检查通过，反馈仍新鲜。
- `Ready, disabled`：READY/STOP握手等条件满足，仍保持失能。

只有解码计数、没有新鲜有效的反馈，不能判定通信已通过。默认电控许可未开启时也可能持续等待READY；详细诊断含义见“先读我-部署与通信测试.md”。按 Ctrl+C 结束本测试。

## 5. 后续导航编译

通信测试完成后再编译完整导航。若小电脑已经有ROS雷达驱动工作区，传入它实际的环境脚本路径：

```bash
bash scripts/build_nav.sh /绝对路径/雷达驱动工作区/install/setup.bash
```

如果当前终端已加载该驱动，可执行：

```bash
bash scripts/build_nav.sh
```

SDK和ROS驱动包是两项不同内容。导航需要目标环境能找到 `livox_ros_driver2`；此包已排除原仓库自带的旧驱动，避免同名包冲突。

此步骤只编译，不自动启动导航或使能底盘。实车IP、驱动参数、IMU单位、安装外参、云台零位、底盘安全许可和地图需分别核对。完整架构见 `src/rm_chassis_comm/SENTRY_ARCHITECTURE.md`。
