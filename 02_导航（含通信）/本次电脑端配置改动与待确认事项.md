## 6. 所有尚未确认或未完成的事项

| 项目 | 当前未知/缺项 | 后续确认方式与影响 |
| --- | --- | --- |
| 云台 yaw 转轴位置 | 相对底盘原点的 XYZ 未测量 | 量取并填 `yaw_pivot_xyz`，占位零值不能视为底盘中心 |
| 云台 pitch 转轴位置 | 相对 yaw 轴坐标的 XYZ 未测量 | 量取并填 `pitch_pivot_xyz` |
| 两轴编码器标定 | 固定 ECD 零位、正方向和速度符号未知 | 电控侧标定真实编码器，不能用上电角或 IMU 绝对 yaw 替代 |
| 云台关节反馈 | 实机是否产生本协议 0x22/46B 状态包未知 | 检查真实采样、标定状态、时间戳推进和断流处理 |
| 完整双板固件 | 新包未包含完整烧录工程；本轮未集成/构建/烧录两份 MCU 固件 | 在云台/底盘工程分别接入新协议、USB/CAN 回调、RTOS 队列、周期处理及本地安全许可 |
| 现有板上固件版本 | 本轮未读回或检测当前应用固件 | 之前测通的 0xA5 固件不能默认兼容新 0x5A 协议 |
| 应用 USB 端口 | 当前仅有下载器串口，云台应用 USB 不在 | 将云台 C 板自身 USB 接电脑，核对实际 by-id；不要拿下载器 ttyACM0 代替 |
| 板间 CAN 物理口 | 云台 CAN1/2、底盘 CAN1/2 的最终接法未再次确认 | 结合实际接线和固件回调选择；PC 配置不能决定 MCU 接哪个口 |
| CAN 速率/滤波/队列 | 两板最终速率、滤波、ID 冲突及有界有序发送队列尚未实测 | 核对 0x320/0x321，验证六片完整传输、丢片超时、总线负载；旧 0x311/0x312 不是此协议 |
| CAN 电气连接 | 共地、终端电阻、滑环/线束干扰与连接可靠性未验收 | 现场核对 H/L、参考地、端接与错误计数 |
| 底盘轮向和运动学 | 已知 M3508+C620+四轮全向；实际轮序、正方向、轮径、减速比和轮距未完成新方案实测 | 架起逐轴核对，再校准 SI 速度到电机 RPM；不能只套原代码常量 |
| 实测速度反馈 | 新固件是否返回真实轮速估计、有效标志是否正确未知 | 无真实新鲜测量时清 MEASURED，不能回显指令充当实测 |
| 本地许可与遥控 | 新双板的遥控通道、模式仲裁和导航允许条件未联调 | 遥控/人工/急停必须最终覆盖导航；旧单板测试不能代替新双板测试 |
| 停车行为 | 断 USB、断 CAN、关遥控、任务停摆时的实际停车/制动未测量 | 实测 MCU 独立 TTL、安全许可和电机停止；PC 禁止使能不代表已验证制动距离 |
| 精确雷达外参 | 当前 0.20 m/零 RPY 来自用户名义安装；实际小倾角、固定刚度和安装误差未精标 | 最终装车后核验；若改装到旋转云台，当前固定雷达 TF 必须重新设计 |
| 代价地图轮廓参考系 | 新包用 gimbal_yaw_fake；当前尺寸来自底盘中心 | 结合真实转轴偏置、方向及突出结构核对，避免轮廓中心或包络错误 |
| 时钟与实时延迟 | PC/MCU 软件映射在实际 USB/CAN 下的误差未知 | 检查关节反馈年龄、时钟映射和丢帧；软件估计不是硬件同步 |
