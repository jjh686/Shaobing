## 第一步：明确参数和保留现场

`GIMBAL_PITCH_ANGLE_KP`统一为25，删除初始化末尾的Pitch覆盖赋值。速度PI最初保留500/1000，后续因用户实测纠偏振幅增大，将Ki降为200；本轮因小目标经常不跟随，单独回调Ki到500，速度Kp仍500。积分上限2000 raw（1 N·m）、力矩换算10/20000、最终限幅4 N·m均保留。Yaw仍使用原来的参数与覆盖赋值。

新增RAM环形记录：`gimbal_pitch_trace`，128条、50ms一条，可保存约6.4秒。记录跟踪目标、限幅后的驱动目标、IMU Pitch/Roll、速度、编码器相对角、原始/处理后速度参考、P/I力矩、两项补偿、请求/下发/反馈力矩、模式、使能、电机状态及门控原因。丢失目标后再记录约2秒，然后保留；重新进入跟踪或门控状态变化后继续记录。不会写Flash、改USB协议或额外打开串口。

查看`gimbal_pitch_trace_total/count/next`了解记录进度；最新条目下标为`(next+127)%128`，按`sequence`排序还原顺序。`mode`是板端gimbal模式，不是USB的0/1。尚未进入过跟踪时持续循环记录，不能宣称已保留一次跟踪。

`sequence`最后提交。程序运行中外部读取并非原子，优先在记录已保留时分批读取；读取条目前后核对序号，变化则该条无效。不要为读记录暂停带电控制程序。诊断工具每次读取有预算，建议先读单条，再按小切片导出，勿一次读整个数组。

`tick`为记录时刻，`motor_tick`为最近电机反馈时刻；源命令、PI与CAN反馈可能相差一个任务周期，不能当作同一物理瞬间的测量。20Hz诊断不是1kHz示波器，持续跟踪超过6.4秒会覆盖早期样本；设备复位后RAM历史消失。

## 第二步：补偿与最终输出保护

新增`application/gimbal/gimbal_pitch_control.c/.h`。补偿用canonical Pitch正方向的N·m表示，最后才由驱动应用电机方向符号。

重力模型：`A*cos(pitch-zero) + B*sin(pitch-zero)`。默认A/B均为0，未标定时不猜测补偿方向或负载。运动方向翻转不改变重力模型的符号；HOLD/TRACKING切换保留重力支撑和原有积分，真正STOP则清除动态状态。补偿建立速度限制为5 N·m/s。更改编译期系数并重新启动后，积分从零开始；不支持在运行中直接改补偿内部状态/系数，否则可能与原有积分叠加。

可选起动摩擦辅助：正、负Pitch方向分别配置，默认均为0。误差达到0.15°且接近静止时可介入，0.05°内退出；这两个阈值不阻止正常PI纠偏。辅助平滑建立，运动开始后撤出，单次起动辅助窗口默认0.25秒，随后按斜率退到零；不会在同一持续误差下周期性重踢。误差回到退出阈值内或换向才重新允许一次尝试。它不识别机械卡死，也不关闭正常PI输出，不能当堵转保护。

Pitch机械软边界限制移到专用驱动最终输出处，覆盖PI、补偿及通用CURRENT_FEEDFORWARD的总和。软边界处仅阻止向外力矩，允许向内力矩；与原控制契约相同，没有解除限位。最终力矩饱和时只撤回本周期进一步加重饱和的积分增量，保留已有负载支撑；边界拦截时清除积分，避免继续向外积累。故障、超时、STOP与复位请求门控仍优先。

软边界仍为启动相对±20°；单独命名的外侧故障界限仍为±21°，没有扩大原范围。超过外侧界限、反馈异常或电机报错不自动恢复。新增硬界限驱动检查意味着只要驱动在使能时观察到越界，就会锁存停机，原因保存在`fault_reason_flags`；若应用先停机，记录中的机械角和门控位仍可说明越界。软边界以内的“最低抬不起来”如由机械干涉导致，代码不能承诺恢复。

`pitch_motor->last_gate_flags`为当次输出原因位；`fault_reason_flags`保留首次锁存原因，显式清故障成功才清除：

| 位值 | 含义 |
| --- | --- |
| 1 | STOP |
| 2 | 已锁存故障 |
| 4 | 电机反馈超时/未收到 |
| 8 | 外部IMU反馈超时 |
| 16 | 目标指令超时 |
| 32 | 电机未使能或硬件状态不正常 |
| 64 | 控制器复位请求尚待处理 |
| 128 | 输入/计算异常或健康门控不通过，需结合其他位 |
| 256 | 软边界阻止总力矩向外输出 |
| 512 | 总力矩达到最终限幅 |
| 1024 | 相对编码器超过外侧故障界限/机械角无效 |

多个原因可以同时出现。记录中的P/I/重力/摩擦为canonical Pitch方向；requested/applied/reported力矩为电机方向。比较时需考虑`GIMBAL_PITCH_OUTPUT_SIGN`。反馈力矩为电机协议换算值，不是外置力矩传感器的独立校验。

## 第三步：起动与提前减速

仅Pitch加入参考速度处理，Kp保持25。第一版使用速度上限90°/s、加速度360°/s²、制动规划360°/s²。用户烧录后反馈纠偏时振荡增大，后续抑振测试配置改为速度上限45°/s、加速度180°/s²、制动规划120°/s²。处理顺序：角度误差得到速度参考 → 根据目标/软边界剩余距离限制速度 → 限制加速 → 速度PI → 补偿 → 总力矩保护 → CAN。

采用停止距离关系`v <= sqrt(2*a*remaining_distance)`。因为原应用每次最多提供5°跟随误差，当前5°误差时停止距离上限约34.6°/s（上一版约60°/s）；1°误差时上限约15.5°/s（上一版位置环给25°/s）。降低制动规划参数表示假设制动能力较小、提前降低速度参考，不是降低速度P项的实际制动力。参考在换向、误差清零或边界收紧时可以立即降低，保护/减速优先于加速平滑。

这些是参考限制，不是对实际角速度、加速度或制动力的保证。重力尚未补偿时，小偏差起动问题可能仍在，甚至初始输出建立更平缓；不能只烧这一版就宣称死区已消除。需根据负载实测再调速度/制动参数。`GIMBAL_PITCH_MOTION_LIMIT_ENABLE=0`可单独回退参考处理，保持补偿/保护能力；这不是整套源码回退开关。

## 实机后续顺序

1. 本轮已经依据编码器/Roll历史证据同步修正板端与视觉安装矩阵；上机先核对真实上下运动与变换后的Pitch、Pitch角速度及编码器同向同幅。90°主轴修正后仍需测剩余安装倾角，不把本机数学测试当作实机标定。
2. 核对实际行程和上电锚点。正常软范围应在机械止挡内留出制动余量；故障范围也必须在真实允许行程内。当前±20/±21只是保留旧值，不代表已完成机械标定。
3. 先以重力/摩擦系数0验证小角度动作、减速、HOLD保持及软边界返回，并读取保留的记录。
4. 在几个常用姿态分别从上下两侧到位，等待稳定后记录支撑力矩；对同一姿态双向到位的数据取平均可减少部分摩擦偏差，单次HOLD积分不是纯重力。拟合有符号A/B及安装角偏置，记录使用的单位与方向。现有PI积分已到上限且姿态漂移的数据不能用于稳定支撑标定。
5. 写入已测得的重力系数，重新编译和烧录；观察总输出，确认不会托过头，再调整剩余积分和速度环。
6. 若补偿后仍有小误差卡滞，查明机械间隙/摩擦，再按正负方向测起动力矩并填写摩擦辅助系数，不填写猜测值。
7. 分别验证±0.5°、±1°、±3°、±5°附近目标变化、换向、丢失目标保持、软边界返回；比较起动延迟、峰值速度、过冲、稳定误差与温度。外侧故障界限不要用撞击实机方式验证。

重心前移优先通过重部件靠近转轴、线束余量或机械平衡改善。代码补偿不增加电机可持续出力能力；4 N·m软件限幅不是额定连续力矩。
