# 本机桌面启动

本机从 2026-11-22 起，桌面“装甲板实时识别”使用本工程：

`/home/wangjiaming/文档/GitHub/RM_11_13/01_自瞄（含通信）`

- 双击图标：海康相机识别及 C 板 USB SP 通信，并向本机决策发布跟踪状态。
- 右键图标 → “仅识别预览（不连接C板）”：使用本工程相机及模型，仅显示识别预览。
- 两种入口都会先增量编译 `build/auto_aim_test`，本目录内的源码修改在下次启动时生效。
- 默认配置为 `configs/live_usb_sp.yaml`，模型使用本工程 `assets/`。
- 运行日志和截图位于 `build/runtime/logs/`，桌面启动日志名为 `desktop_*.log`。
- 图像窗口按 `Q` 退出，按 `R` / `B` 切换跟踪颜色，按 `S` 保存截图。

终端启动方式：

```bash
cd '/home/wangjiaming/文档/GitHub/RM_11_13/01_自瞄（含通信）'
bash scripts/run_live_usb_sp.sh
# 仅识别预览
bash scripts/run_live_usb_sp.sh --preview
```

当前配置固定使用序列号为 `315D324A3034` 的 C 板；更换 C 板时更新
`configs/live_usb_sp.yaml` 中的 `com_port`。USB 入口沿用 mode0/1 联动，关闭开火请求。

IMU 安装矩阵 `R_gimbal2imubody` 必须与 `05_云台/application/gimbal/gimbal_config.h`
中的 `GIMBAL_TO_IMU_ROTATION` 一致，当前为 `[0,1,0,-1,0,0,0,0,1]`。
C 板回传原始四元数，视觉与板端均通过 `M^T R(q) M` 换算；切换工程时须保留此配置。
2026-11-22 的只接收核对中，单位阵导致约 12.76° 的俯仰坐标偏差，当前矩阵与板端吻合。
验证记录位于 `build/verification/imu_mount_check_20261122.json`；此核对未发送云台控制。

正常运行时，识别画面新增每秒更新的性能统计：`FPS` 为实际处理帧率，`CAM` 为海康
采集线程交付的帧率，`RX/TX` 为 USB 有效接收/成功写入频率。`age95` 为最近一秒内
图像从 SDK 交付到本轮处理完成的耗时 P95，不包含曝光、相机到电脑传输及电机响应。
结构化数据保存在 `build/runtime/logs/performance_日期_时间_进程号.jsonl`。
详细实测见 [帧率实测-20261122.md](帧率实测-20261122.md)。
