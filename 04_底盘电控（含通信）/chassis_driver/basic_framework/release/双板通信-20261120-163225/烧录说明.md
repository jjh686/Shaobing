# 底盘 C 板：双板通信-20261120-163225

推荐烧录 `DiPan_Board.elf`，也可选同名 HEX；BIN 起始地址为 `0x08000000`。三种格式是同一程序，选一种即可。

接线：CAN2 接云台 CAN1；CAN1 接四个 C620/M3508。板间 CAN 为 1 Mbps，H 对 H、L 对 L，两板共地。

底盘运动宏为 1；遥控许可、四电机在线、STOP 会话和 TTL 仍必须满足。

两块板必须分别连接 SWD，核对目标板后烧写、校验并复位。本次仅生成固件，未访问硬件、未烧录、未进行实物通信验收。

配套固件与测试步骤见总工程 docs/双板通信固件生成与烧录-20261120.md。烧录后先用 tools/zero_test.sh 执行 10 秒 STOP/ACK 测试。
