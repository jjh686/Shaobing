# 云台 C 板：双板通信-20261120-163225

推荐烧录 `Gimbal_USB_CAN1.elf`，也可选同名 HEX；BIN 起始地址为 `0x08000000`。三种格式是同一程序，选一种即可。

接线：USB 接小电脑；CAN1 接底盘 CAN2；UART3/DBUS 接 S.BUS。板间 CAN 为 1 Mbps，H 对 H、L 对 L，两板共地。

本包来自 04 目录自带配套中转工程；GIMBAL_BOARD 已启用，云台执行器安装门控仍为 0。

两块板必须分别连接 SWD，核对目标板后烧写、校验并复位。本次仅生成固件，未访问硬件、未烧录、未进行实物通信验收。

配套固件与测试步骤见总工程 docs/双板通信固件生成与烧录-20261120.md。烧录后先用 tools/zero_test.sh 执行 10 秒 STOP/ACK 测试。
